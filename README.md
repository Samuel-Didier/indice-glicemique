# Indice glycémique

Application web légère en français, inspirée de l’architecture du [Carnet Bassa](https://github.com/Samuel-Didier/dictionnaire-bassa). Données transcrites du PDF fourni.

## Utilisation
Ouvrir `index.html` via un serveur statique (le navigateur bloque `fetch` en `file://`). L’application ne dépend d’aucune bibliothèque : recherche instantanée, filtres, détail et règles d’or.

Les valeurs sont indicatives et ne remplacent pas un avis médical.
